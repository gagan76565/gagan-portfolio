## Run locally

This is a static site; no build step or package installation is required.

```bash
git clone https://github.com/gagan76565/gagan-portfolio.git
cd gagan-portfolio
```

Open `index.html` in a browser, or serve the directory locally:

```bash
python -m http.server 8000
```

Then visit http://localhost:8000.

## Deployment

Render is configured to publish the repository root from the `main` branch. Automatic deployment is enabled, so commits to `main` trigger a new static-site deployment.

## Resume link

The View Resume and Download Resume actions point to the same Google Drive file. The Drive file needs viewer access for portfolio visitors; confirm its sharing setting before distributing the portfolio.
